# Ornith 1.5 MLX conversion and migration

Experiment period: 2026-08-20 through 2026-08-30.
Outcome: passed scoped conversion and installed-stack checks.
Disposition: incorporated into Geer 0.2.0 and retained in 0.3.0.

## Question and scope

Could Geer replace its Ornith 1.0 artifacts with reproducible Ornith 1.5
conversions while preserving installation, model selection, and repository
retrieval? This was a conversion and integration exercise, not a reproduction
of upstream benchmark scores.

## Configuration

- Upstream: `ornith-ai/Ornith-1.5-35B-A3B`, revision
  `e4dfb35a93d4b6822a811a7676f3488514abe7e2`.
- Conversion: MLX 0.32.0, MLX-LM 0.31.3, MLX-VLM 0.6.3; BF16 source,
  unfused-expert layout transformation, affine quantization, group size 64.
- Artifacts: 6-bit revision `c3d5e9008c891ef96da42630ef8b484aef696669`
  and protected mixed 4/8-bit revision
  `03a2eeaa494beb6a44aaca3695473ab2ede47837`.
- Runtime: oMLX 0.5.3, revision
  `31d07a7fdbbb499d4520188fb7e8f7bdbfe4c770`, with the then-current
  Claude Code launcher and T3 Code integration.
- Validation host: Apple M4 Max with 128 GB unified memory. This record does
  not establish measurements on smaller-memory hosts.

## Result

Conversion manifests and source/output hashes were recorded for both
artifacts. The 6-bit distribution records 29,090,460,346 bytes; the mixed
distribution records 21,644,076,559 bytes.

The installed 0.2.0 package reused the verified 6-bit model, returned a local
response, passed retrieval and launcher checks, and exposed Ornith 1.5 in T3's
model selector. Migration hid the retired 1.0 model from selection. The
resulting release included a signed and notarized installer.

The model cards explicitly distinguish upstream benchmark claims from Geer's
own conversion results. They also record that the pinned conversion path
removed the upstream MTP tensors. Multimodal metadata and tensor provenance
alone do not establish image-serving quality or MTP support.

## Decision and revisit condition

Retain the verified Ornith 1.5 artifacts for the released integration. Revisit
conversion when the upstream revision, tensor transformation, quantization,
or runtime changes. Requalify images or MTP separately before claiming those
capabilities. Use the recorded model notices and provenance when reviewing
distribution; this experiment makes no additional licensing determination.
