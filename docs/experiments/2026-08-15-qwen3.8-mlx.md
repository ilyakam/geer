# Qwen3.8 MLX conversion, context, and interfaces

Experiment period: 2026-08-15 through 2026-08-16.
Outcome: passed scoped checks on a 128 GB host; near-limit latency incomplete.
Disposition: historical Claude-based integration, not incorporated into 0.3.0.

## Question and scope

Could protected MLX quantization preserve useful Qwen3.8-27B behavior and fit
Geer's local model lifecycle? Conversion, deterministic quality checks,
interfaces, memory, and context were tested. Smaller-machine qualification
and upstream benchmark reproduction were outside the completed evidence.

## Configuration

- Source: `Qwen/Qwen3.8-27B`, revision
  `1d4bf0f2ff6012fd82039f2fa52739d0dd7c60c0`, 55,586,114,863 bytes.
- Conversion: MLX 0.32.0, MLX-LM 0.31.3, MLX-VLM 0.6.3; protected
  affine 6-bit and mixed 4/8-bit, group size 64; vision and native MTP
  tensors retained. An 8-bit reference remained a local candidate.
- 6-bit artifact: `ilyakam/Geer-Qwen3.8-27B-6bit-MLX`, revision
  `26e46ace34317b8e04377e7a65615cedb0475897`, 26,673,982,643 bytes.
- Mixed artifact: `ilyakam/Geer-Qwen3.8-27B-4-8bit-MLX`, revision
  `2cdef25ea18a5e202a1bac51761ced21fe345d81`, 24,205,241,562 bytes.
- Serving: oMLX 0.5.3 revision
  `31d07a7fdbbb499d4520188fb7e8f7bdbfe4c770`; Apple M4 Max, 128 GB
  unified memory, macOS 15.7.7. Context work used BF16 KV and one requested
  model resident at a time in the final configuration.

## Result

BF16 and 6-bit passed 10/10 deterministic quality and interface cases, with
matching output hashes. The mixed artifact passed the same cases, although
some reasoning and tool-continuation text differed. This small suite does not
establish general benchmark parity.

The quality result applies to the intended thinking mode. Historical working
code also represented low, medium, extra-high, and disabled reasoning as
request-time profiles sharing one artifact. That implementation does not
establish equal quality across modes or expose them through the released Pi
adapter.

Both published snapshots were verified against their local file manifests.
Loaded model footprints were about 25.27 GiB for 6-bit and 22.99 GiB for
mixed precision. Live model switches left only the selected model resident.
Inline base64 images passed; remote image URLs returned HTTP 400 through
this pinned interface.

Needle retrieval passed through 104,905 measured input tokens. A 250,000-token
request ran for ten minutes without an OOM or swap growth, then was cancelled
because prefill latency was impractical. An earlier 158,549-token run had two
models resident and grew swap; it does not qualify the final configuration.
Cache hits were observed, but this record contains no controlled cache speedup.

The 48 GB mixed and 64 GB 6-bit profiles remained provisional. A memory budget
or a successful 128 GB run does not establish either physical-host result.

## Decision and revisit condition

Preserve the conversion evidence, including the cancelled long-context run.
Before bringing this model into the Pi product, qualify that harness path and
the actual target hardware. Revisit near-limit context when prefill behavior
changes, using bounded latency and memory measurements. Revisit 32 GB only
after a materially smaller safe profile exists; the mixed weights plus the
estimated 64K BF16 KV cache already approached the recorded process budget.

The separate [MTP follow-up](2026-08-16-qwen3.8-mtp.md) supersedes
the early single-workload MTP result.
