# Original Ornith 1.0 6-bit conversion

Experiment date: 2026-07-24.
Outcome: passed scoped conversion and inference checks.
Disposition: superseded by [Ornith 1.5](2026-08-20-ornith-1.5-mlx.md).

## Question and scope

Could Geer independently convert the upstream BF16 model into a reproducible
MLX artifact and use it for local text and tools? This established the first
model path, not a comparative coding score or full-context qualification.

## Configuration

- Source: `deepreinforce-ai/Ornith-1.0-35B`, revision
  `5df2ed3f675c7beaa490328cc70bb573b65fb660`, 70,250,400,102 bytes.
- Conversion: `qwen3_5_moe_unfused_experts` transformation, affine 6-bit,
  group size 64; MLX 0.32.0, MLX-LM 0.31.3, MLX-VLM 0.6.3.
- Initial experimental artifact: `ilyakam/Geer-Ornith-1.0-35B-A3B-6bit-MLX`,
  revision `bd7b8b380f792d3b8f254d8747767da22f686262`.
- Host: Apple M4 Max with 128 GB unified memory; oMLX 0.5.3,
  revision `31d07a7fdbbb499d4520188fb7e8f7bdbfe4c770`.

## Result

Conversion and manifest hashes were verified. The model loaded and passed
bounded text, streaming, token-counting, tool-call, and tool-result checks.
Reported loaded memory was about 30.5 GB in the initial run. Warm latency and
throughput observations lacked matched prompt, completion, cache, and pressure
conditions, so they are retained as smoke-test evidence rather than benchmarks.

Other quantizations were inspected as sizing references; they were not all
converted or evaluated by Geer. Upstream BF16 scores were not results for
this quantization. The native 262,144-token context was not fully validated.

The later 0.1.0 release pinned a different snapshot,
`a093cdd0dcc846e99a3224aea61452799640f0ea`. That later identity is not a
substitute for the initial experimental revision when reproducing a result.

## Decision and revisit condition

Retain this conversion baseline and its limited evidence. For new work,
compare with the current Ornith artifact rather than reactivating 1.0 by
default. Revisit this exact baseline only for a regression investigation or
matched quality/context study that needs the older model.
