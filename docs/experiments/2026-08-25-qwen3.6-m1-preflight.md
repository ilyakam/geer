# Qwen3.6 MoE preflight for a 16 GB M1

Experiment date: 2026-08-25.
Outcome: inspected only; no full model download or inference qualification.
Disposition: resident configuration rejected; streaming feasibility unproven.

## Question and scope

Could a Qwen3.6 35B-A3B artifact fit the physical 16 GB M1 through Geer's
runtime, and would bounded expert residency materially change that budget?
This was artifact and runtime source inspection, not a generation test.

## Configuration

- Candidate: `unsloth/Qwen3.6-35B-A3B-GGUF`, revision
  `a483e9e6cbd595906af30beda3187c2663a1118c`,
  `Qwen3.6-35B-A3B-UD-IQ4_NL.gguf`, 18,040,888,288 bytes.
- File SHA-256:

- Declared upstream: `Qwen/Qwen3.6-35B-A3B`, revision
  `995ad96eacd98c81ed38be0c5b274b04031597b0`; GGUF architecture `qwen35moe`.
- Inspected Geer runtime: oMLX 0.5.3 revision
  `31d07a7fdbbb499d4520188fb7e8f7bdbfe4c770`, serving MLX directories.
  A 64 MiB range read supplied the GGUF header and tensor table.

## Result

The 16.80 GiB GGUF already exceeded the target's unified-memory capacity
before the rest of the stack. Geer's pinned MLX serving path did not load
this GGUF. Moving expert computation to the CPU would not create a separate
physical memory pool on this Mac.

The tensor table attributed about 14.41 GiB to routed experts and 2.38 GiB
to other tensors. A calculated eight-slot expert pool was about 0.45 GiB,
putting a hypothetical model-side tensor floor near 2.83 GiB. Those figures
assumed a loader that retained only bounded expert slots. They were not
measured allocations and excluded runtime, KV, operating-system, and tool
overhead. A small pool could also severely constrain prompt-processing
batch size and SSD traffic.

No full candidate weights were downloaded, no streaming runtime was
implemented, and no inference or physical-M1 performance result was obtained.

## Decision and revisit condition

Keep the resident and streamed-memory questions separate. Revisit only when
a pinned, provenance-reviewed native runtime supports this architecture and
bounded expert residency. First measure exact output, stopping behavior,
resident and transient memory, SSD traffic, prefill, and decode on a lab
host. Physical-M1 and current Pi/T3 qualification would follow separately.
An upstream result for a different model or M1 variant does not clear these
gates.
