# Security Policy

## Supported Versions

Geer is an early proof of concept. Security fixes are provided for the latest
published release only.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Email
`geer@ilyakam.com` with:

- the affected version and environment;
- a description of the impact;
- minimal reproduction steps or a proof of concept; and
- any suggested mitigation.

Please avoid including credentials, private repository contents, prompts,
completions, model caches, or other personal data. You can expect an initial
acknowledgement within seven days. The maintainer will coordinate validation,
remediation, disclosure timing, and credit with you before publishing details.
